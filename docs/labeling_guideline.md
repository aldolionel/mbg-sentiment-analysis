# Panduan Labeling Sentimen

Dokumen ini berisi aturan awal untuk memberi label sentimen social media posts terkait Program Makan Bergizi Gratis (MBG). Panduan ini berlaku untuk teks pendek informal dari X/Twitter, TikTok, atau platform media sosial lain.

Label yang digunakan:

- `positif`
- `negatif`
- `netral`

## Aturan Umum

1. Beri label berdasarkan sentimen utama dalam teks.
2. Jika teks berisi pujian dan kritik, pilih label yang paling dominan.
3. Jika teks hanya bertanya, memberi informasi, atau tidak menunjukkan sikap jelas, gunakan label netral.
4. Sarkasme perlu diperiksa secara hati-hati berdasarkan konteks kalimat.
5. Jangan menggunakan identitas pengguna sebagai dasar labeling.
6. Abaikan mention, username, link, atau metadata platform saat menentukan sentimen.

## Positif

Label positif digunakan untuk teks yang mendukung, mengapresiasi, atau menunjukkan harapan baik terhadap Program MBG.

Contoh:

1. "Program MBG bagus banget buat bantu anak-anak sekolah."
2. "Semoga makan bergizi gratis bisa jalan terus dan merata."
3. "Ini kebijakan yang bermanfaat kalau pelaksanaannya benar."
4. "Setuju dengan MBG, banyak keluarga yang terbantu."
5. "Anak-anak jadi lebih semangat sekolah kalau dapat makanan bergizi."
6. "Program seperti ini penting untuk kesehatan siswa."

## Negatif

Label negatif digunakan untuk teks yang menolak, mengkritik, meragukan, atau menyampaikan kekecewaan terhadap Program MBG.

Contoh:

1. "Program MBG cuma buang-buang anggaran kalau tidak diawasi."
2. "Saya ragu makanan gratis ini bisa benar-benar bergizi."
3. "Takutnya nanti banyak korupsi dalam pelaksanaan MBG."
4. "Lebih baik dananya dipakai untuk memperbaiki fasilitas sekolah."
5. "Program ini kelihatan bagus di awal saja, praktiknya belum tentu."
6. "Kalau menunya asal-asalan, MBG tidak ada gunanya."

## Netral

Label netral digunakan untuk teks yang bersifat informatif, bertanya, tidak menunjukkan dukungan atau penolakan, atau sentimennya tidak jelas.

Contoh:

1. "MBG itu mulai diterapkan kapan?"
2. "Menu makan bergizi gratisnya apa saja?"
3. "Program ini untuk semua sekolah atau tertentu saja?"
4. "Saya baru dengar tentang Program MBG."
5. "Anggaran MBG berasal dari mana?"
6. "Di daerah saya belum ada informasi soal MBG."

## Catatan untuk Teks Ambigu

Teks yang sangat pendek seperti "mantap", "parah", atau "gimana nih" perlu dilihat konteksnya. Jika konteks tidak tersedia, annotator dapat memberi catatan pada kolom `notes` dan mendiskusikannya pada tahap validasi manual.
